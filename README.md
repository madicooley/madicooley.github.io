# Madison Cooley’s portfolio

The launch site is plain HTML, CSS, and JavaScript. Preview it from this directory with:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open <http://127.0.0.1:8000/>. The intended GitHub Pages source is the root of the `main` branch. The Projects & Notes work and its restoration context are on the local `full-portfolio` branch.
